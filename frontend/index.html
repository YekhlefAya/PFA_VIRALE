Validation des 3 Hypothèses de Recherche ($H_1, H_2, H_3$)

L'importance des variables mesurée sur les données réelles Bluesky confirme directement la théorie formulée dans le Cahier des Charges :

1. Hypothèse H2 (Graphe) +40 % d'impact

L'audience maximale du relais (f_g_log_followers_max) est la variable n°1. Sans compte influent pour propager le sujet hors de son cercle, la viralité est impossible.

2. Hypothèse H1 (Temps) +30 % d'impact

Le taux d'engagement précoce par post (f_t_eng_per_post) arrive en 2e position. Une accélération forte dès les 30 premières minutes signale un buzz naissant.

3. Hypothèse H3 (NLP) +12 % d'impact

L'intensité émotionnelle et les accroches textuelles (f_s_emotion_lex) départagent les sujets à dynamique similaire.
